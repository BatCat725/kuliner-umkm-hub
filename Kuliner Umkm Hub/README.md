# Kuliner UMKM Hub

Prototipe web sederhana untuk tema **Kuliner dan UMKM** — platform yang mempertemukan pelaku usaha kuliner mikro/kecil dengan pembeli.

## Struktur
- `index.html` — halaman landing/beranda
- `login.html` — halaman masuk
- `register.html` — halaman daftar usaha
- `dashboard.html` — dashboard pemilik usaha (ringkasan pesanan, produk, rating)

## Cara pakai
Buka `index.html` langsung di browser, atau push seluruh folder ini ke repository GitHub dengan format:

```
umkm-hub/kuliner-umkm-hub
```
